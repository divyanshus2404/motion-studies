# Motion & interaction studies

Three live studies of how payments and credit can feel in motion, by [Divyanshu Singh](https://divyanshu-singh-resume-portfolio.vercel.app). Each interaction is clickable and has its duration, easing and reasoning written next to it.

| Study | What it covers |
|---|---|
| [Pay in 3, in motion](pay-in-3/) | Plan switcher, price split, a pay button that morphs into its loader, an instalment tracker |
| [Your limit, revealed](limit-reveal/) | Credit onboarding: KYC progress, a limit ring that counts up, a tilting card, skeleton loading |
| [Small moments, observed](observed/) | Everyday Indian objects turned into payment interactions: shutter, head shake, kirana chit, gullak |

Hand-built in HTML, CSS and vanilla JavaScript, with no build step and no animation library, so every curve is visible in the source. Motion turns off when the system asks for reduced motion.

## Run or deploy

Open `index.html` in a browser, or import this repo into Vercel as a static site (no settings needed).
